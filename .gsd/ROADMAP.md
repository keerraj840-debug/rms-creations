# Roadmap — RMS Creations

> **What is this document?**  
> This document tracks the development stages of **RMS Creations** in simple terms — what is already done and what is planned next.

---

## Stage 1: Core Online Shop & WhatsApp Ordering (Completed)

| What was built | Description | Status |
|----------------|-------------|--------|
| **1. Design & Warm Theme** | Warm boutique colors (terracotta, chocolate, blush) and smooth dark mode. | ✅ Done |
| **2. Customer Pages** | Home page, Ganpati pooja kits, hamper lookbooks, return gift calculator, and contact. | ✅ Done |
| **3. WhatsApp Ordering** | Fast 1-tap WhatsApp ordering with pre-filled message details. | ✅ Done |
| **4. Order Tracker** | Pop-up on every page where customers can track order status. | ✅ Done |
| **5. Admin Control Panel** | Private login, photo cropper, product bundling, stock tracking, and store settings. | ✅ Done |
| **6. Plain-English Documentation** | Simple guides explaining PRD, Style, TRD, Architecture, and Database. | ✅ Done |

---
