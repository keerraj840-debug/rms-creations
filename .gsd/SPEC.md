# Project Specification — RMS Creations

> **Status:** `FINALIZED`  
> **What is this document?**  
> This document lays out the goals and boundaries for the **RMS Creations** website in plain, simple language.

---

## 1. What is this project?

**RMS Creations** is a website for an artisanal gift hamper shop. It allows customers to easily browse beautiful gift hampers, festive pooja kits (like Ganesh Utsav boxes), and bulk party return gifts. Customers can tap one button to order directly with the shop owner on WhatsApp, or track existing orders anytime. The shop owner gets an easy admin panel to manage products, photos, and orders.

---

## 2. Main Goals

1. **Simple, Beautiful Online Catalog:** Show high-quality photos of gift boxes with clear prices, contents, and bulk discounts.
2. **Easy WhatsApp Ordering:** Tap one button to open a ready-to-send WhatsApp message with the exact box name and price already filled in.
3. **Easy Admin for the Shop Owner:** Allow the owner to quickly upload photos, add new gifts, change prices, and track orders from their phone or laptop.
4. **Fast and Mobile-Friendly:** Loads in around 1 second on mobile phones, with warm colors and easy-to-read text.

---

## 3. What is NOT in Scope for this Phase (Non-Goals)

* Automatic credit card payment gateways (payments are handled easily and directly over UPI/WhatsApp).
* Native phone app store downloads (the website is mobile-responsive and works directly in any browser).

---

## 4. How We Know It Works (Success Checklist)

- [x] All customer pages work smoothly (Home, Ganpati Hampers, Hampers, Return Gifts, Gallery, Offers, Contact).
- [x] WhatsApp order buttons open WhatsApp with pre-filled messages.
- [x] Order Tracking pop-up lets customers check their order status.
- [x] Light and Dark modes switch smoothly and save user preference.
- [x] Admin panel allows password login, photo cropping, item bundling, and order status updates.
